# Quiz Arena - Interactive Quiz App 🎮

## Features ✨

- **Category Selection**: Choose between **General Knowledge** and **Technology** quizzes.
- **Difficulty Levels**: Select between **Easy** and **Hard** levels for a challenge.
- **Timer**: A countdown timer adds excitement as you answer questions.
- **Question Navigation**: Move between questions with the **Next** button.
- **Results**: View a summary of your performance at the end of the quiz.

## Technologies Used 💻

- **HTML**: Structure of the quiz app.
- **CSS**: Styling to create a user-friendly interface.
- **JavaScript**: Handles quiz logic, question navigation, timer, and result display.
